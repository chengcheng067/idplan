本应用未集成任何会采集个人信息的第三方 SDK。

应用内不存在统计、广告、推送、崩溃监控、社交分享、第三方登录、地图、支付等任何类型的第三方数据服务。前端代码中没有一行向第三方发送数据的逻辑；后端唯一的外呼目标由部署者自己在环境变量里填写。

03唯一的外部服务调用

为避免「没有 SDK」被误读成「完全离线」，这里明示唯一两类可能触及外部网络的调用。它们都不是 SDK，而是应用自己写的一小段请求代码：

调用实现方式触发条件携带的数据
检查更新（GitHub Releases） 桌面主进程内直接发起的一个 HTTPS 请求，不依赖任何第三方库 仅 Windows 桌面版：启动约 8 秒后一次，或手动点击 仅 User-Agent: id-plan-desktop。无任何用户数据
可选的自然语言解析 服务端一个标准的 HTTP 请求，发往部署者自己填写的地址 默认关闭；需部署者显式配置地址、密钥、模型名三项后才可用 你输入的那一句话（≤500 字）。不含项目库、客户名单、成员信息

这两项都不涉及向开发者回传数据。第一项的目标是 GitHub 的公开接口，第二项的目标由部署者自己指定。开发者既不运营也不中转。

上述全部第三方组件均适用其各自的开源许可证（MIT、ISC、Apache-2.0 等），完整清单与版本号见随附的 package-lock.json。ID Plan 自身的代码采用专有许可（保留所有权利）。

本应用在分发时不修改、不删除任何第三方组件的许可证声明。

05如何自行核验

我们理解「声称无采集」需要能被验证。你可以用以下任意方式自行核查：

  • 看网络请求：打开浏览器的开发者工具 → 网络面板，正常使用应用，观察是否有除「你自己的 NAS 地址」之外的请求域名。
  • 看源码：项目为公开仓库，可直接检索是否存在统计 / 埋点相关代码。
  • 看依赖：对照本清单逐项核对依赖清单文件，本清单已把所有运行时组件全部列出，未作筛选。
  • 断开外网：把 NAS 或电脑断网（仅保留局域网），除「检查更新」与「自然语言通道」外，功能应完全正常。

Third-Party SDK List (English)

ID Plan · Effective November 3, 2026

This application integrates no third-party SDK that collects personal information.

There is no analytics, advertising, push-notification, crash-reporting, social-sharing, third-party-login, maps, or payment SDK anywhere in the app. Not a single line of front-end code sends data to a third party. The backend's only outbound call goes to an address the deployer sets themselves.

Categories verified as absent: web/app analytics, crash monitoring, product analytics, session recording / heatmaps, ad attribution, push notifications, social sharing and third-party login, maps and location services, payments, live-chat support, cloud/object storage, online font and icon CDNs, and any custom tracking or beacon.

What the app does use is a small set of general-purpose open-source libraries, listed in full in the Chinese section above so the claim can be audited:

  • Front end: React, React DOM, React Router, Dexie (local IndexedDB wrapper), Zustand, Zod, dayjs, clsx, lucide-react (icons bundled, not loaded from a CDN), html2canvas (local print-to-PNG rendering). None collects data; none makes network calls.
  • Server (runs only in your own NAS container): Fastify (local HTTP framework — request logs go to the container's stdout and are managed by your NAS Docker logging, never to an external service and never into the business database), @fastify/cors, better-sqlite3 (SQLite driver; the database file lives in your own NAS volume). None collects data.
  • Desktop shell: Electron 44, configured with context isolation on, Node integration off, and renderer sandbox on. No permission request handler is registered, and no camera, microphone, location, or notification permission is requested. Its only business use of the network is the optional update check against GitHub's public releases API, which sends only a fixed User-Agent: id-plan-desktop — no device information, no account, no project data — and occurs only in the Windows desktop edition.
  • Build-time only (not shipped): Vite, TypeScript, Tailwind CSS, PostCSS, Autoprefixer, electron-builder, Vitest, jsdom, fake-indexeddb, tsx, concurrently, cross-env.

Every third-party component remains under its own open-source licence (MIT, ISC, Apache-2.0, etc.); the complete list with versions is in the bundled package-lock.json. ID Plan's own code is proprietary, all rights reserved.

How to verify this yourself: open your browser's developer tools network panel while using the app and confirm there are no request domains other than your own NAS address; search the public repository source for tracking code; compare the dependency manifest against the full list above; or disconnect the machine from the internet — everything except the update check and the optional natural-language channel works normally.
