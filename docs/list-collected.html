04数据流向总览

方向是否存在说明

NAS → 用户自行配置的 AI 服务（可选）默认关闭需用户显式配置三项参数才启用；发送内容 ≤500 字；详见隐私政策第 06 节

List of Personal Information Collected (English)

ID Plan · Effective November 3, 2026

Total personal information collected: zero items.

This list enumerates every field and permission that could plausibly be relevant, and marks all of them "No". Its purpose is to document what is not collected:

  • Name / nickname — not collected, not stored
  • Phone number — not collected, not stored
  • Email address — not collected, not stored
  • Government ID / real-name information — not collected
  • Device identifiers (IMEI / MAC / OAID / advertising ID) — not collected
  • Location — not collected, permission not requested
  • Contacts / SMS / call logs — not collected, permissions not requested
  • Photos / camera / microphone — not collected, permissions not requested
  • Clipboard contents — not collected; clipboard is written only when you press "Copy", never read
  • Biometrics — not collected
  • Usage behaviour / analytics / click tracking — not collected
  • Crash logs / performance data — not collected
  • IP address / tracking cookies / browser fingerprint — not collected
  • Account credentials — no account system exists
  • Payment or transaction data — not collected (the app has no paid features)
  • Search history — not collected

Permissions requested: network access (outbound) and local browser storage. Nothing else — no camera, microphone, contacts, SMS, photo library, location, notifications, background auto-start, or Bluetooth/NFC.

Business data you enter yourself (project names, addresses, client names, contract amounts, stage names and notes, task titles, team member names and roles, an optional free-text contact field, avatar colours, password hashes, contract file names and text digests, travel and budget records, company logo, UI preferences, local service tokens) is written by you and stored only on your own device or your own NAS. It is never uploaded, and we have no interface that can read it. All of it can be deleted by you at any time from within the app or by removing the local database / Docker volume.
