02法律声明

我们不会向任何第三方共享你的个人信息，不会转让你的个人信息，也不会公开披露你的个人信息。

2.1 关于共享

本应用不设置任何将数据传输至开发者以外第三方的通道。应用内不存在统计分析、广告投放、崩溃监控、推送服务、社交分享、第三方登录等可能引发共享的功能模块，也未集成任何会采集个人信息的第三方 SDK（详见《第三方 SDK 清单》）。

2.2 关于转让

因开发者不持有个人信息，不存在「运营主体变更导致个人信息转让」的情形。若开发者身份或应用所有权发生变更，因不涉及任何个人信息资产，你的数据仍完整保存在你自己的设备或 NAS 上，不受影响。

2.3 关于公开披露

本应用不设公开主页、不生成公开分享链接、不向搜索引擎提交任何用户数据。你在应用内录入的任何内容都不会以公开形式出现。

04例外情形

依法需要向有权机关提供信息时，我们的处境是：我们不持有任何用户数据，因此在技术上无从提供。若收到此类要求，我们只能如实说明这一点。

请注意区分以下两种情形，它们均不构成「开发者共享」：

4.1 用户自己的 NAS 内部流转

NAS 版中，浏览器与你自己的 NAS 后端之间会传输数据。这两端都属于你自己，属于你的设备之间的通信，不是向第三方共享。

4.2 用户自行配置的 AI 服务（可选，默认关闭）

这是唯一可能出现「数据离开你的局域网」的场景，且完全由你决定。

  • 该通道默认关闭。只有你在部署 NAS 版时显式配置了服务地址、访问密钥、模型名三项全部，它才可用；缺任何一项即拒绝服务。
  • 被发送的是你输入的那一句话（上限 500 字），不包含你的项目库、客户名单、成员信息或任何其他数据。
  • 接收方是你自己选择的服务商，与你直接建立关系。开发者不参与该次传输、不托管密钥、不经手内容，也不从中获得任何信息。
  • 你可以把它指向本机的离线模型（例如你自己部署的 Ollama），这样数据不会离开你的机器。
  • 一旦你选择了外部服务商，该服务商对数据的处理适用其自身的隐私政策。如果你不希望任何数据出境，请不要配置这个通道。

Personal Information Sharing List (English)

ID Plan · Effective November 3, 2026

Third-party recipients: none.

We do not share, transfer, or publicly disclose any personal information. The table of recipients is intentionally empty — not because it is unfinished, but because no recipient exists. The developer holds no personal information, so there is nothing that could be shared.

There is no analytics, advertising, crash-reporting, push-notification, social-sharing, or third-party-login module in the app, and no third-party SDK that collects personal information is integrated (see the Third-Party SDK List).

No entrusted processing and no joint processing: the developer has not engaged any data processor (no cloud provider, no data-processing vendor), and there are no co-processing arrangements.

Legal requests: because we hold no user data, we are technically unable to produce it in response to any authority's request. We can only state that fact.

The only scenario where data could leave your local network is the optional natural-language channel, which is off by default. It works only if you, as the deployer, explicitly set all three of: endpoint URL, API key, and model name. In that case the single sentence you typed (max 500 characters) is sent to the provider you chose — which may be a local offline model. The developer does not participate in that transmission, never hosts your key, never sees the content, and derives no information from it. If you configure an overseas endpoint, that is your deployment decision, not an act of the developer.

Exercising your rights: viewing, copying, correcting, deleting, and withdrawing consent all happen directly inside the app and take effect immediately — no request to us is needed. There is no account to cancel, because no account system exists. Only interpretive questions require contacting us at [contact email].
