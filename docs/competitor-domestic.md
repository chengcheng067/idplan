# 《ID Plan》国内（中国市场）竞品调研报告

> 调研对象：面向室内设计师的项目节点排程 / 团队进度管理工具 **ID Plan**（作者本人为室内设计师，最初为自家行业打造）
> 调研范围：中国市场（国内），覆盖通用型项目管理 SaaS、设计/装修行业垂直工具、甘特图/排期专项工具与开源方案
> 调研方式：WebSearch 联网检索（公开资料 + 厂商官网 + 测评文章），截至 2026-09
> 性质：**只读调研，未修改任何业务代码**

---

## 0. 执行结论（先看这里）

**一句话结论**：国内"项目管理 SaaS"赛道已被阿里/字节/腾讯/禅道等巨头与大量"装修行业 ERP"填满，但**真正"专为设计师的排期/进度"、且同时具备"阶段模板驱动 + 自动排期算法 + 离线优先 + 可私有部署（NAS）+ 甲方用 A4 打印稿导出"的产品，目前是空白**。ID Plan 卡在一个被巨头忽视、又被重 ERP 看不上的细分工位上，差异化空间真实存在。

**三个核心判断**：

1. **通用 PM SaaS（Teambition / Worktile / 飞书项目 / TAPD / 禅道 / PingCode / CODING）** 功能高度重叠且以"研发/通用协作"为中心，**没有内置"设计项目阶段模板"**，甘特图是通用任务条，不是"方案→施工图→采购→施工→验收"这种行业阶段语义。ID Plan 的"阶段驱动 + 自动排期（锚点钉住、残值归并）"是它们不具备的。
2. **设计/装修行业 ERP（小叮当、泛微EPM、酷家乐、三维家、明源云等）** 是"CRM+报价+材料+财务+施工"全家桶，重、贵、上手门槛高，**对单设计师/小工作室是杀鸡用牛刀**。ID Plan 轻量、聚焦"排期与进度"、本地优先、价格可远低于订阅制。
3. **最接近的直接竞品是"蓝燕云（LanyanCloud）"**——它同样主打"室内设计+工程一体化 SaaS、甘特图、AI 排期建议"，但其为云端 SaaS、重协作；ID Plan 的"离线优先 + 绿联 NAS 私有部署 + A4 打印导出 + 自动排期算法"构成可防御差异。

**主要风险**：① 飞书多维表格 / Teambition 低代码能"够用替代"一部分需求；② 设计师群体习惯 Excel + 微信建群，迁移意愿低；③ ID Plan 为个人/小团队开发，缺少大厂的支持、培训、移动端、生态集成；④ 品牌认知度几乎为零。

## 6. ID Plan 的差异化空间与竞争环境

### 6.1 差异化优势（ID Plan 有，别人没有/不强）

1. **设计阶段的"原生语义"**：项目天然按"方案→施工图→采购→施工→验收"等阶段组织，而非通用任务板。这是所有通用 PM 与设计 ERP 都没做的"行业纵深"。
2. **自动排期算法**：给定项目起止日期，按阶段模板自动切分时间，支持**锚点钉住 + 残值归并**。通用工具只能手动拖，进度猫等也不会"智能切分"。
3. **离线优先 / 数据私有**：React + Dexie（IndexedDB）前端优先，数据在本地；可选 Fastify+SQLite 服务端。**隐私敏感型设计师/甲乙方不愿上云的场景**是空白。
4. **三种交付形态（Electron 桌面 + 绿联 NAS UPK 私有部署 + 纯 Web）**：尤其 NAS 自托管，契合国内"想自己掌控数据"的小工作室，是 SaaS 不愿做的形态。
5. **对客交付物（A4 PNG 打印稿）**：一键导出可直接发给甲方，是设计行业特有的"排期对外沟通"刚需，竞品均无。
6. **由室内设计师为室内设计师而做**：领域共情与模板质量（阶段模板库）是外部团队难快速复制的。
7. **轻量 + 低/零成本潜力**：相比 ERP 动辄数千元年费，ID Plan 可走免费/低买断/小额订阅，对独立设计师极度友好。

### 6.2 差异化劣势（ID Plan 弱于别人）

1. **缺团队协作基建**：离线优先意味着默认无多端实时同步，而 Teambition/Worktile/飞书天然云协作。需要 NAS/服务端才具备团队协同。
2. **缺移动端与工地现场能力**：无 App、无扫码报工、无现场拍照留档，而工程宝/装内助/美家帮以此为核心。
3. **无业务全链路**：不含 CRM 获客、报价、材料、财务，被小叮当/泛微EPM 等 ERP 全覆盖。
4. **品牌与信任为零**：个人/小团队开发，无 SLA、无实施培训、无大客户案例；企业采购有顾虑。
5. **生态集成缺失**：未对接企业微信/钉钉/飞书、酷家乐/三维家、微信提醒等，孤岛风险。
6. **甘特/报表深度有限**：相比 Worktile/禅道企业版的关键路径、资源负载、BI 大屏，ID Plan 当前更轻。

### 6.3 真实竞争环境画像

- **巨头（阿里/字节/腾讯/禅道）** 在"通用协作"层碾压，但**不屑于做"设计师排期"这种窄众纵深**，其甘特图为通用任务条。ID Plan 不与它们正面竞争，而是做"它们看不上的细分"。
- **装修 ERP（小叮当等）** 在做"全家桶"，**看不上"只做排期"的轻量市场**，且价格/复杂度劝退独立设计师。ID Plan 正是填补"轻量排期"空缺。
- **最接近的对手是蓝燕云**：同打"设计+工程 SaaS + 甘特 + AI 排期"，但其为云端重协作。ID Plan 用"离线优先 + NAS 私有 + A4 导出 + 自动排期算法 + 低价"形成错位。
- **低代码（飞书多维表格/Teambition）** 是"够用替代"威胁：部分设计师会用多维表格自建甘特。需靠"开箱即用的设计阶段模板 + 自动排期"降低自建门槛来对抗。

## 7. 威胁与产品建议（供 roadmap 参考）

| 维度 | 现状 | 建议 |
|---|---|---|
| 最大直接威胁 | 蓝燕云（设计+工程 SaaS，含 AI 排期） | 强化"离线/私有+低价+A4 导出"差异，避免被云端功能碾压 |
| 最大隐性威胁 | 飞书多维表格/Excel+微信 的"够用替代" | 提供**开箱即用的设计阶段模板库**与一键自动排期，把"自建成本"压到零 |
| 最明显短板 | 无移动端/工地现场 | 优先补"移动端只读 + 进度拍照回填"，或对接企业微信/钉钉 |
| 信任短板 | 个人开发、无品牌 | 突出"由在职室内设计师打造"、放出真实项目模板样例、做开源/免费层建立口碑 |
| 商业化 | 可避开订阅红海 | 走"免费个人版 + NAS/团队版买断/小额订阅 + 模板市场"组合，对标禅道开源打法 |
