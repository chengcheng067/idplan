# ID Plan · Windows 桌面版安装说明

> 适用于 Windows（64 位）。装完就是一个独立的桌面应用，桌面 + 开始菜单都有「ID Plan」快捷方式。
> 数据存在**本机**；如需工作室多人共享，请用绿联 NAS 版（团队共享数据）。

---

## 一、安装

1. 下载 `IDPlan-0.8.2.0001-Setup.exe`：[GitHub Releases](https://github.com/chengcheng067/idplan/releases)
   > 文件名里的 `0.8.0` 是产品版本，末四位 `0008` 是构建号。同一版本可能有多份构建，以构建号最大的为准。
2. 双击安装包。
3. 安装向导会问安装位置，**可以改目录**（不是强制装 C 盘）。
4. 装完桌面和开始菜单都有「ID Plan」快捷方式，双击即可打开。

> ⚠️ **SmartScreen 提示**：安装包没有代码签名证书，Windows 可能提示「未知发布者」。这是正常现象，点 **更多信息** → **仍要运行** 即可。

---

## 二、使用说明

- **首次打开**：会引导你确立身份。你是设计师本人 → 选「我是管理员」，填姓名。
- **数据存哪**：本机（浏览器 IndexedDB）。离线可用，不依赖网络。
- **切换身份**：顶栏身份入口可切换 / 退出（支持同机换人）。
- **备份**：顶栏「保存备份 / 加载备份」，一键导出 JSON / 导入恢复。

---

## 三、团队共享

Windows 版数据在本机，**不适合多人协作**。要团队共享同一份数据，请部署 **绿联 NAS 版**（数据集中存在 NAS，所有成员自动看到同一份）：

- 📄 [UPK 应用包安装教程](upk-install-tutorial.md)（推荐，最省事）
- 📄 [Docker compose 安装教程](nas-deploy-tutorial.md)

---

## 四、升级

重新下载最新版安装包，覆盖安装即可。Windows 版数据在本机，升级不影响（未清理缓存则保持不变）；如需清空重来，卸载后重新安装。
